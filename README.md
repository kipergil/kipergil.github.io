# Mustafa Kipergil — personal website

Personal portfolio of **Mustafa Faruk Kipergil**, Senior Software Architect (event-driven .NET on Azure), live at
[kipergil.github.io](https://kipergil.github.io).

- **About** — summary, focus areas, highlights, testimonials and companies
- **Resume** — experience, Microsoft certifications, skills and interests
- **Tools** — side projects deployed on Vercel (table tennis, UK Turkish community, AI & productivity)
- **Contact** — opens a pre-filled email to me

Static HTML/CSS/JS, served by GitHub Pages. Based on the open-source
[vCard](https://github.com/codewithsadee/vcard-personal-portfolio) template (MIT).

Tool thumbnails in `assets/images/tools/` are screenshots of each live deployment.
